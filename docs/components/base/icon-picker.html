IconPicker 图标选择器 ​

选择图标和背景色，选中值通过 v-model 同步。

交互示例 ​

选择图标
背景颜色
选择图标

已选图标：未选择

vue
<script setup>
import { IconPicker as XIconPicker } from '@xto/base'
import { ref } from 'vue'
const icon = ref('')
const background = ref('#4F46E5')
</script>

<template>
<x-icon-picker v-model="icon" v-model:background="background" />
<p>已选图标：{{ icon || "未选择" }}</p>
</template>
